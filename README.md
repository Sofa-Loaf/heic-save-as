# HEIC Save As

Free, client-side HEIC → JPG/PNG converter.

Drop one or more `.heic` / `.heif` files, pick JPG or PNG, Save as / download. Runs in the browser. No account. No Stripe. No upload.

**Live:** https://28to3.me/apps/heic-save-as.html
